# 나머지 10개 실험 미션 (게임 G2) — 기기 확인 결과

SM-P200(`R54M800WFEM`), low(Compatibility, 3D 0.75배 + MSAA 2x), 2026-10-26~27. `bench_device.sh low <runs> 90 60`, `--auto-drag=4`, 10분 지속 측정은 하지 않았다(`OPBENCH_SUSTAINED=0`). 측정 중에는 두기두기의 예측 질문(대화창 + 그림 단추 2개)이 90초 내내 열려 있다. 데모가 질문에 답하지 않기 때문이다. 기기 설정(화면 꺼짐·밝기·전원)은 바꾸지 않았고, 앱 데이터도 지우지 않았다(`adb install -r`). 마지막에 이 브랜치 빌드를 설치해 두었다.

## 승인 표에서 바꾼 문턱

문턱은 조작 범위 안에서 닿아야 하고, 기본 조건만으로 깨지면 안 된다. 그래서 아래처럼 바꿨다(값은 공식과 실험 상수로 계산, `tests/lab_mission_checks.gd`로 확인).

| 실험 | 승인 표 | 바꾼 값 | 이유 |
|---|---|---|---|
| 자유 낙하 | 4 → 7 → 10 m/s | 10 → 12 → 15 m/s | 기본(지구, 5 m)이 v = √(2gh) = 9.9 m/s라 1·2단계가 그냥 깨진다. 지구 8 m 최대는 12.5 m/s라서 15는 목성(5 m, 15.7 m/s)이 필요하다(3단계 = 중력 생각) |
| 용수철 | 1 → 2 → 3 m | 1.5 → 2 → 2.4 m | 막대 끝까지 당겨도 2.5 m라 3 m는 닿지 않는다. 기본 당김 1.2 m가 1 m를 넘는다. 판정은 새 관찰값 "놓은 자리 x₀"(가로 용수철이라 늘어난 길이는 당긴 만큼) |
| 마찰 밀기 | 가벼운 → 보통 → 무거운 | 그대로(무게 선택 조건) | 질문의 "강철"을 실험 선택지 이름 "금속"으로 맞췄다 |
| 회전(지렛대) | 150 → 100 → 60 N | 그대로 + "20 kg 짐" 조건 | 조건이 없으면 짐을 1 kg으로 줄여 바로 깬다. 기본(중간 힘점)은 186.9 N |
| 궤도 | 반 → 한 → 두 바퀴 | 그대로 + 출발 반지름 조건(4 m → 5 m → 2 m) | 기본이 3 m 원 궤도라 발사만 하면 다 깬다. 5 m는 3 m/s면 멀리 날아가 느리게, 2 m는 별에 부딪혀 빠르게 쏴야 한다 |
| 부력 | 50 → 100 → 140 kg | 70 kg 넘게(75~) → 90 kg 넘게(95) → 작은 통 40 kg 넘게(45) | 100 L 통은 100 kg 미만만 뜨고(ρ < 1000), 150 kg까지 있는 슬라이더에서 100·140 kg은 뜰 수 없다. 기본 70 kg이 50을 넘는다 |
| 진자 | 2 → 2.5 → 3 s | 3 → 3.5 → 4 s | 기본(지구, L = 2 m)이 2.9 s라 1·2단계가 그냥 깨진다. 4 s는 달 중력이나 아주 큰 각도가 필요하다 |
| 도르래 | 150 → 80 → 40 N | 150 → 100 → 50 N + "20 kg 짐" 조건 | 20 kg 짐은 4줄이어도 49 N이라 40 N은 닿지 않는다. 조건이 없으면 1 kg 짐으로 바로 깬다 |
| 충돌, 빗면 마찰 | 2 → 4 → 6 m/s, 1 → 2 → 3 m/s² | 그대로 | 기본 조건은 1.5 m/s(충돌)와 멈춤(빗면)이라 1단계부터 바꿔야 한다 |
